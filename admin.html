¿Cómo consigo mi clave? (solo se hace una vez)
  1. Entra a GitHub con tu cuenta K3V1N01122 y abre este enlace para crear un token.
  2. Token name: Panel Importadora KP. Expiration: 1 año (o la que prefieras).
  3. Repository access: "Only select repositories" y elige IMPORTADORA-KP-WEB.
  4. Permissions → Repository permissions → Contents: "Read and write".
  5. Toca Generate token, copia el código que empieza con github_pat_ y pégalo aquí.

No compartas esta clave: con ella se puede cambiar el sitio. Si la pierdes o sospechas que alguien la tiene, bórrala en GitHub y crea otra.
